# AI Native Textbook for Physical AI and Humanoid Robotics

This is a [Docusaurus](https://docusaurus.io/) project for an AI Native Textbook focusing on Physical AI and Humanoid Robotics.

## Deployment to Vercel

This project is configured for deployment on Vercel.

### Automatic Deployment
1. Push this repository to GitHub
2. Connect your GitHub repository to Vercel
3. Vercel will automatically detect the Docusaurus project and build it
4. The site will be deployed with the configuration in `vercel.json`

### Manual Deployment
To deploy manually to Vercel:
1. Install the Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this directory
3. Follow the prompts to configure your project

## Local Development

To run this project locally:

### Installation
```bash
npm install
```

### Running locally
```bash
npm run start
```

### Building for production
```bash
npm run build
```

The build command creates a `build` directory with the static files for deployment.
